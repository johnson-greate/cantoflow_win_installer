# CantoFlow —— 廣東話語音輸入（Windows）

> 連㩒兩下 <kbd>F2</kbd>、講嘢、再連㩒兩下，
> 啲字就會自動打喺你游標嗰度。

Word、Excel、WhatsApp Web、email、任何打得字嘅地方都用得。

**語音辨識全部喺你部電腦入面行，你把聲唔會送去任何伺服器。**
第一次下載完模型之後，就算完全冇網絡都用得。

## 安裝

**1.** 下載，開個檔案

**2.** Windows 大機會彈「**Windows 已保護您的電腦**」
→ 撳「**其他資訊**」→「**仍要執行**」

呢個係因為個檔案冇買數碼簽章，唔係中毒。

**3.** 裝到 `%LOCALAPPDATA%\Programs\CantoFlow`，**唔使管理員權限**

**4.** 開程式 → 設定 → 授權 → 貼上你嘅授權碼 → 撳「啟用」

**5.** 啟用之後先會下載語音模型
⏳ 約 **2.4 GB**，視乎網速 20 至 40 分鐘。請保持連線。
💾 請預留約 **3.5 GB** 磁碟空間。

**6.** 連㩒兩下 <kbd>F2</kbd> 開始講嘢

---

## 電腦要求

| | |
|---|---|
| 系統 | Windows 10 或 11（64-bit） |
| 記憶體 | **8 GB 或以上** |
| 磁碟 | 約 3.5 GB |
| 網絡 | 只喺第一次下載模型時需要 |
| 顯示卡 | 不需要，行 CPU |

記憶體較細嘅電腦，可以喺系統匣揀 **0.6B** 細模型（用少約一半記憶體，
速度快啲，但人名地名會冇咁準）。

## 遇到問題

系統匣（右下角）CantoFlow 圖示撳右鍵 → **「回報問題…」**

佢會喺你桌面產生一個報告檔，同時開埋檔案總管同一封填好嘅電郵。
**將個檔拉入封電郵寄出就得**，唔使你自己搵任何嘢。

🔒 報告**唔會**包含：你講過嘅任何說話、你嘅 API key、你詞庫入面嘅詞條。
產生之前個畫面會寫明畀你睇。
